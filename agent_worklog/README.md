# Agent Work Log

This folder is the working record of the AI coding agents maintaining the Agent Collab Treaty itself. It is the same treaty this repo ships, applied to its own development.

- [`work_log.md`](work_log.md) — the session log, newest first: decisions and why, approaches tried and dropped, and how each change was verified. Older entries are in [`work_log_archive/`](work_log_archive/).
- [`next_steps.md`](next_steps.md) — unfinished work and open follow-ups.

Agents start from [`AGENTS.md`](../AGENTS.md) at the repo root, which also holds this repo's conventions; [`project_overview.md`](../project_overview.md) maps the codebase. The README that adopters get in their own folder comes from [`template/`](../template/).
